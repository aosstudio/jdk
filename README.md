# AOSStudio JDK

AOSStudio JDK builds a headless OpenJDK 21 for Gradle, Kotlin and AOSP build tools. The first target is 64-bit Linux on x86-64 with glibc.

The terms in [LICENSE](LICENSE) cover AOSStudio's build scripts, workflows and documentation. OpenJDK uses GPL version 2 with the Classpath Exception where marked. The published JDK archive carries the applicable upstream licenses and third-party notices.
