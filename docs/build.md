# Build and use AOSStudio JDK

The first build targets Ubuntu 26.04 on Linux x86-64 with glibc. Use a checkout on disk with a path containing no spaces. The [source lock](../locks/openjdk.mk) records the OpenJDK release tag, its commit and the SHA-256 of the downloaded source archive.

## Local build

Run these commands from the repository root.

```sh
sudo apt-get update
xargs --arg-file=ci/ubuntu-26.04-packages.txt sudo apt-get install --yes --no-install-recommends
make build
make verify
```

The build uses Ubuntu's `openjdk-21-jdk-headless` package as its Boot JDK. Set `BOOT_JDK` to the directory of a different OpenJDK 21 installation if needed. Set `BUILD_JOBS` to adjust parallelism from the default of four jobs. The downloaded source, extracted tree and build outputs are cached under `out/`.

`make verify` unpacks the archives, checks the Linux x86-64 executable and JDK components, compiles and runs a Java 17 JAR, and runs it again with a runtime generated by `jlink`. It also checks that the API documentation can be used as an offline Javadoc link target.

## Artifacts

The build places three archives in `out/dist/`.

| Filename | Contents |
| --- | --- |
| `aosstudio-jdk-21.0.13.1-2-linux-x86_64.tar.gz` | Headless JDK and build provenance |
| `aosstudio-jdk-21.0.13.1-2-linux-x86_64-javadoc.tar.gz` | Matching Java API documentation |
| `aosstudio-jdk-21.0.13.1-2-sources.tar.gz` | Corresponding OpenJDK source archive, shared by all target architectures |

Extract the JDK archive into a directory and set `JAVA_HOME` to its root, which contains `bin/java`. Add `$JAVA_HOME/bin` to `PATH` to use the tools from a shell. For builds that need local Javadoc HTML, extract the documentation archive and use its `api/` directory.

The JDK image retains the upstream module notices. OpenJDK is distributed under GPL version 2 with the Classpath Exception where marked. Keep the matching source archive available alongside distributed binaries and preserve the notices in both the JDK and documentation archives.
